One number in digits and nothing else: the honest count of browser tabs open at that moment. No words, no explanation, no screenshots. The entrant's browser regularly has so many tabs open they lose track of pages — a high two-digit count is the real, lived-in answer.

## The number

> 87

## Run it

```sh
python3 main.py
```

The program writes the number to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network, no input files, no secrets.
